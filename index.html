⚡ One-Tap App Install Available!
Install Masar C1 directly onto your home screen with its own C1 icon.
🤖 Android Phone / Tablet
  1. Save english_mastery_c1.html to your device (or host it free on GitHub Pages / Netlify Drop).
  2. Open it in Chrome.
  3. Tap the ⋮ Menu (top-right) → Add to Home screen or Install app.
في أندرويد: افتح الملف في متصفح Chrome ثم اضغط القائمة (⋮) واختر «الإضافة إلى الشاشة الرئيسية».
🍎 iPhone & iPad (iOS/iPadOS)
  1. Send english_mastery_c1.html to your iPhone/iPad (via AirDrop, WhatsApp, Telegram, or iCloud Drive).
  2. Tap to open it in Safari or Files.
  3. In Safari, tap Share (⬆️) → Add to Home Screen for a full-screen app!
في آيفون وآيباد: افتح الملف في Safari ثم اضغط زر المشاركة (⬆️) واختر «إضافة إلى الشاشة الرئيسية».
🚀 Host on GitHub Pages (Best for Phone & Tablet App Install + Live Cloud AI)
  1. Create a new public repository on GitHub.com and upload the files from masar_c1_github_pwa.zip (or upload this file renamed to index.html).
  2. Go to repository Settings → Pages, set Branch to main, and click Save.
  3. Open your link (https://your-username.github.io/repo-name/) on your phone or tablet and tap Install App / Add to Home Screen. Both Offline Mode and Live Keyless Cloud AI will work automatically!
